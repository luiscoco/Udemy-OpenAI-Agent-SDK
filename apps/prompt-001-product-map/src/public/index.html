    Execution modes
    
      
    
        Classroom demo uses scripted model outputs and a local dataset. It
        offers repeatable playback for teaching. Live API invokes the installed
        SDKs using server-side configuration.
      
    
      
    Run live examples
    
      
    
        Copy .env.example to .env, set
        OPENAI_API_KEY, and restart. Agents API also needs
        ENABLE_AGENTS_API=true and project access. Codex needs
        ENABLE_CODEX=true and local authentication. Live runs use
        your configured account and can incur usage charges.
      
    
      
    Record the lesson
    
      
    
        Run npm run record to capture a repeatable classroom
        walkthrough. The recording uses a fresh local server and saves a WebM
        video in recordings/.
